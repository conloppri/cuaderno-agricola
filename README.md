# 🌾 Cuaderno de Campo Digital - Proyecto FCT

¡Bienvenido/a al repositorio del **Cuaderno de Campo Digital**! Este proyecto es una aplicación web diseñada para digitalizar la gestión agrícola, permitiendo a los agricultores llevar un control riguroso de sus parcelas, cultivos y tratamientos de forma sencilla y eficiente.

Este software fue desarrollado de forma colaborativa como proyecto principal durante el periodo de **Prácticas en Empresa (FCT)** del Grado Superior en DAM.

## 🚀 Características Principales

La aplicación web ofrece una solución integral para la gestión agrícola a través de los siguientes módulos:

*   **🔐 Control de Acceso:** Sistema de login y registro seguro para la gestión de usuarios (agricultores/administradores).
*   **🗺️ Gestión de Parcelas:** Registro, visualización y organización de terrenos y tipos de cultivo.
*   **🚜 Registro de Actividades (Cuaderno de Campo):** Automatización del registro de tratamientos fitosanitarios, abonados, riego y cosechas, cumpliendo con las normativas actuales.
*   **📊 Interfaz Dinámica:** Consultas rápidas y validaciones en el lado del cliente para mejorar la experiencia de usuario.

---

## 🛠️ Stack Tecnológico

*   **Backend:** [PHP](https://www.php.net/) (Lógica de negocio, gestión de sesiones y API interna).
*   **Frontend:** [JavaScript](https://developer.mozilla.org/es/docs/Web/JavaScript) (Interactividad y peticiones asíncronas/Fetch), [HTML5](https://developer.mozilla.org/es/docs/Web/HTML) y [CSS3](https://developer.mozilla.org/es/docs/Web/CSS) (Estructura y diseño responsivo).
*   **Base de Datos:** [MySQL](https://www.mysql.com/) (Diseño relacional para el almacenamiento de usuarios, parcelas y registros).
*   **Herramientas:** Visual Studio Code, XAMPP y Git/GitHub.
